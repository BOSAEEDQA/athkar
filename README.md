# أذكار الصباح والمساء

تطبيق شخصي للقراءة والعدّ ومواقيت الصلاة. يعمل دون إنترنت بعد تحميل ملفاته للمرة الأولى.

الرابط: https://BOSAEEDQA.github.io/athkar/

## التثبيت على الآيفون

1. افتح الرابط في Safari ثم Share → Add to Home Screen → Add.
2. افتح الأيقونة الجديدة أثناء الاتصال، وانتظر «جاهز للاستخدام بدون نت».
3. جرّب وضع الطيران، أغلق التطبيق وافتحه من الأيقونة.

لا يحتاج Expo Go أو تشغيل الكمبيوتر. النسخة الجديدة لا ترسل تنبيهات في الخلفية؛ حساب المواقيت يتم محليًا عند فتحها بحسب المدينة والإعدادات المحفوظة. تحديث التطبيق وزيارة روابط المصادر يتطلبان الإنترنت.

## البيانات

- 25 ذكرًا للصباح و25 للمساء، السحب والانتقال دون اشتراط إكمال التكرار.
- عدّادات مخصصة مستقلة محفوظة حتى التصفير اليدوي.
- الحساب بمكتبة Adhan، مع تعديل دقائق كل صلاة ووقت الإقامة واختيار حساب العصر.
- البيانات تبقى في تخزين المتصفح، ولا تُرفع إلى المستودع أو إلى خادم.
- احفظ ملفًا من «الحفظ والتثبيت → حفظ نسخة احتياطية». مسح بيانات الموقع أو إزالة تخزينه قد يفقد البيانات والملفات المخزنة دون اتصال.
- للاستيراد من النسخة السابقة في Expo: الإعدادات → تصدير بياناتي، ثم استيراد النص/الملف في النسخة المثبتة الجديدة. النقل ليس تلقائيًا بين التطبيقين أو بين الأجهزة.
- الاستيراد يعرض معاينة ويطلب تأكيد الاستبدال، ويحفظ النسخة السابقة محليًا للتراجع.

## التطوير

Node.js 22 أو أحدث، ثم:

```sh
npm ci
npm test
npm run build:web
npm run preview
```

المعاينة: `http://127.0.0.1:8787/athkar/`. الناتج `dist/` يعمل على HTTPS أو localhost. يحتوي على manifest وService Worker يخزّن جميع الملفات، بما فيها الخطوط، ويعرض التحديث عند توفره دون مسح البيانات. المسارات نسبية لتعمل تحت مسار GitHub Pages.

## النشر

الفرع `main` للكود. الفرع `gh-pages` يحتوي فقط على ناتج `dist/` المتحقق منه. إعداد GitHub Pages: Deploy from a branch → gh-pages → / (root). لإصدار جديد ابْنِ الناتج، واختبر العمل دون اتصال، ثم انشر محتويات `dist/` على فرع `gh-pages`.

## المصادر والخصوصية

النصوص والمراجع في `src/adhkar.json` وروابط التوثيق من إسلام ويب. الاختبارات تتحقق من سلامة الكتالوج والعدد والترتيب؛ لا تُغني عن مراجعة شرعية مستقلة. خط Cairo مرخّص بـ SIL Open Font License (مرفق في `assets/Cairo-OFL.txt`). الحساب من `adhan` و`luxon`. إحداثيات المدن العامة مضمّنة، دون طلب إذن الموقع. GitHub يعالج طلبات استضافة الملفات عند الاتصال، لكن التطبيق لا يرسل إليه بيانات العدّادات أو النسخ الاحتياطية. لا تحليلات أو إعلانات أو حسابات داخل التطبيق.
